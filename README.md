# ⌨️ KEYTAP: 커뮤니티 기반 타건 콘텐츠 플랫폼

> **"구매자는 가격이 아닌 '소리'와 '느낌'으로 제품을 결정합니다."**
> KEYTAP은 타건음과 타건감 데이터를 중심으로 유저의 취향을 분석하고, 브랜드 공식몰로 연결하는 '경험 중심'의 키보드 발견 플랫폼입니다.

---

## 🚀 사업 모델 및 전략적 가치 (BM)

단순한 판매 중개를 넘어 브랜드사가 광고비 리스크 없이 실제 유저 유입 데이터를 확보하고, 구매 전환 성과를 검증할 수 있는 환경을 구축합니다.

- **자사몰 유입 극대화**: 고품질 타건 사운드 콘텐츠로 구매 의사를 높인 유저를 추적 코드가 포함된 링크를 통해 브랜드 공식몰로 직접 연결합니다.
- **리스크 없는 파트너십**: 초기 입점비나 광고비 부담을 없애고, 실제 유입 성과를 바탕으로 협업하는 상생 모델을 지향합니다.
- **데이터 기반 라인업 확장**: 유저의 '찜' 목록과 모델별 '비교 횟수'를 분석하여 시장성이 검증된 카테고리를 중심으로 위탁 커머스 영역을 넓혀갑니다.

## ✨ 주요 서비스 기능

1. **인터랙션 메인 화면**: 키보드 그래픽 효과를 통해 유저의 호기심을 자극하고 서비스 유입 유도
2. **가상 타건 체험**: 모델별 실제 타건 오디오 파일을 활용하여 웹상에서 직접 소리를 들어보는 경험 제공
3. **스마트 제품 탐색**: 여러 제품을 한눈에 비교하고 개인의 취향에 맞는 키보드를 찾는 최적화된 화면 구성
4. **관리자 대시보드**: 실시간 접속자, 가입자, 인기 모델 등을 시각화하여 데이터 기반의 운영 전략 수립

## 🛠 개발 환경 및 협업 도구

### 개발 기술 (Tech Stack)

- **프레임워크**: `Next.js` (최신 웹 기술 스택)
- **인프라/DB**: `Supabase` (사용자 인증 및 데이터 저장소)
- **라이브러리**: `Zod` (데이터 유효성 검사), `MUI` (사용자 인터페이스 구성 요소)
- **개발 언어**: `TypeScript` (안정적인 코드 작성을 위한 언어)

### 기획 및 협업 도구

- **디자인**: `Figma` (화면 설계 및 프로토타입)
- **문서화**: `Notion` (기획 및 일정 관리)
- **소통**: `Discord`, `Github` (실시간 소통 및 코드 관리)
