## 🚀 사업 모델 및 전략적 가치 (BM)

단순한 판매 중개를 넘어 브랜드사가 광고비 리스크 없이 실제 유저 유입 데이터를 확보하고, 구매 전환 성과를 검증할 수 있는 환경을 구축합니다.

- **자사몰 유입 극대화**: 고품질 타건 사운드 콘텐츠로 구매 의사를 높인 유저를 추적 코드가 포함된 링크를 통해 브랜드 공식몰로 직접 연결합니다.
- **리스크 없는 파트너십**: 초기 입점비나 광고비 부담을 없애고, 실제 유입 성과를 바탕으로 협업하는 상생 모델을 지향합니다.
- **데이터 기반 라인업 확장**: 유저의 '찜' 목록과 모델별 '비교 횟수'를 분석하여 시장성이 검증된 카테고리를 중심으로 위탁 커머스 영역을 넓혀갑니다.

### 1. 웹 진입 인터랙션 페이지

![Interaction Page 시연 GIF](이미지_주소_혹은_경로/interaction.gif)

- **도입 목적**
  - 유저가 사이트에 진입하는 순간부터 시각적인 재미를 제공하여, 서비스 고유의 정체성을 효과적으로 각인시키고 자연스러운 탐색을 유도합니다.
- **구현 방식 및 주요 기능**
  - **동적인 객체 흐름**: 배경 위로 헤드셋, 마우스 등 다양한 전자기기 라인 일러스트가 왼쪽에서 오른쪽으로 부드럽게 흘러가는 무브먼트 구현
  - **마우스 제스처 반응**: 흘러가는 전자기기들 사이에서 '키보드' 오브젝트에 마우스를 올리면(Hover), 마우스 포인터를 따라 해당 키보드의 모델명 툴팁이 활성화
  - **끊김 없는 내비게이션**: 인터랙션 중인 키보드를 클릭하는 즉시 '가상 타건 사운드 체험 페이지'로 직관적으로 전환되는 인터페이스 설계

### 2. 타건 사운드 체험 페이지

![Typing Page 시연 GIF](이미지_주소_혹은_경로/typing.gif)

- **도입 목적**
  - 텍스트나 사양표만으로는 체감하기 어려운 키보드 고유의 '소리'와 '무드'를 화면 너머로 즉각 전달하고, 탐색부터 구매 전환까지의 유기적인 사용자 경험을 제공합니다.
- **구현 방식 및 주요 기능**
  - **인터랙티브 타건 구현**: 페이지 내에서 영문키를 입력하면, 유저가 실제 사용 중인 키보드나 마우스 입력에 반응하여 해당 모델 고유의 타건 오디오가 실시간으로 출력됩니다.
  - **미리 녹음된 오디오 재생**: 키보드 하단의 '재생 아이콘'을 클릭하면, 별도의 타이핑 동작 없이도 미리 오디오 세팅이 완료된 고품질 타건음을 편하게 감상할 수 있습니다.
  - **하단 키보드 카드 슬라이드**: 맨 밑의 화살표 박스를 클릭하면 하단 영역이 확장되며, 다양한 키보드의 이미지, 축 종류, 주요 특징이 요약된 '키보드 카드' 라인업이 활성화됩니다.
  - **유기적인 페이지 내비게이션**: 개별 키보드 카드를 클릭하는 즉시 해당 모델의 전용 타건 체험 환경으로 화면이 전환되며 끊김 없는 탐색 환경을 지원합니다.
  - **취향 아카이빙**: 카드 내 하트 이모티콘 클릭 시, 비로그인 상태일 경우 로그인 페이지로 안전하게 리다이렉트되며, 로그인 후에는 개인 '찜 목록' 보관함에 해당 제품이 즉시 저장됩니다.
  - **공식 사이트 구매 연동**: 카드 레이아웃 하단에 위치한 '구매하러 가기' 버튼을 통해 해당 키보드를 공식적으로 판매하는 외부 브랜드 사이트로 바로 연결됩니다.

### 3. 제품 비교 및 보관함 페이지

![Wishlist Page 시연 GIF](이미지_주소_혹은_경로/wishlist.gif)

- **도입 목적**
  - 유저가 탐색 과정에서 수집한 선호 제품들을 한눈에 아카이빙하고, 복잡한 사양과 타건음을 입체적으로 대조해 보며 최종 구매 의사결정을 내릴 수 있도록 돕습니다.
- **구현 방식 및 주요 기능**
  - **찜 목록 보관함**: 타건 체험 중 하트(관심 제품)를 누른 모든 키보드 라인업이 그리드 형태로 누적되어 시각적으로 노출됩니다.
  - **다중 선택 및 비교**: 각 키보드 카드 좌측 상단에 위치한 '체크박스'를 통해 비교하고 싶은 모델들을 여러 개 선택한 뒤, 우측 상단의 '한눈에 비교하기' 버튼을 눌러 비교 모달 창을 활성화합니다.
  - **사이드 바이 사이드(Side-by-Side) 스펙 대조**: 선택한 제품들이 가로로 나란히 배열되며, 키보드 이미지, 색상 라인업, 가격, 주요 특징(프로파일 종류, 연결 방식, 배터리 용량 등)을 한눈에 대조할 수 있습니다.
  - **비교 화면 내 사운드 플레이**: 제품별 상세 레이아웃 하단에 '타건음 듣기' 오디오 버튼이 각각 배치되어 있어, 서로 다른 키보드의 실제 녹음된 타건음을 제자리에서 바로 재생하고 비교해 볼 수 있습니다.
  - **상단 드롭다운을 통한 실시간 제품 교체**: 비교 창 상단의 '키보드 이름 박스'를 클릭하면 찜 목록에서 선택했던 다른 키보드 리스트가 슬라이드 형태로 노출되며, 이를 선택해 현재 비교 중인 제품을 원하는 모델로 즉시 변경하여 대조해 볼 수 있습니다.
